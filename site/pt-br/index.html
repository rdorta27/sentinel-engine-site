A IA conversa. As regras decidem.

O cliente diz “Não reconheço esta cobrança”. O Sentinel verifica os dados. Depois abre um caso verificado ou entrega ao atendente um processo completo. A conversa continua em espanhol ou português. O Sentinel age apenas quando a política permite. Nunca inventa um dado.

Conceito

O Sentinel transforma uma cobrança contestada em um caso verificado ou em uma transferência. O modelo etiqueta a intenção. O código verifica os dados, aplica a política do banco e confirma o resultado.

Analogia física

Pense em uma agência bancária. O modelo é o funcionário que escuta. A política é o manual de regras. O código é o caixa que confere o recibo antes de mover dinheiro.

Mecânica técnica

  • Entenda. Um modelo de linguagem lê a solicitação e etiqueta a intenção.
  • Consulte. O código lê as cobranças da conta da sessão; o modelo nunca vê o id do cliente.
  • Decida. O motor de políticas roda em código e permite, recusa ou transfere.
  • Verifique. O código confirma que o caso existe antes de informá-lo.
  • Transfira. Fraude ou um valor alto vai para um atendente com os dados verificados.

Quatro casos para testar

O cliente responde em es-MX, es-CO, es-AR ou pt-BR. Os dados são sintéticos. O armazenamento Gold é um mock rotulado.

Caso normal

Uma cobrança, uma confirmação, um número de caso verificado.

Caso ambíguo

Várias compras iguais. O sistema pergunta qual antes de agir.

Valor alto

O sistema não age sozinho. Transfere com os fatos verificados.

Não fui eu

O sistema não decide sobre fraude. Transfere para um atendente.

Casos. A demo ao vivo foi retirada. Os quatro casos e as linhas da demo continuam no replay da demo.

Limites e roteiro

Limites

  • Dados: sintéticos, apenas em espanhol, para três países. Um modelo escreveu os casos em português.
  • Teto: a política deixa resolver 16 de 56 casos simulados (Simulação). O sistema resolve todos. Não resolve nenhum outro.
  • Mocks: o armazém Gold, o login e a sessão, o atendente, o armazém de casos e os valores da política. Cada um mantém o contrato de produção. Mocks.
  • Traduções: um modelo escreveu as páginas em espanhol e português a partir das páginas em inglês. Nenhum falante nativo as revisou.
  • Números: nenhum número é uma medição de produção.

Roteiro: o que não foi construído

  • Customer 360: o saldo não tem uma data de referência utilizável.
  • Investigação de uma cobrança: precisa de dados reais do banco.
  • Conjunto de feedback: os resultados das transferências para atendentes.
  • Assistente de gastos: precisa de saldos e histórico.
  • Consulta de políticas: precisa dos documentos de política do banco.
  • Roteamento de transferências: por idioma e especialidade.
